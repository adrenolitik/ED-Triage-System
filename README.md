# Анестезиологический Триаж

Веб-приложение для медицинской триажной сортировки пациентов по тяжести состояния на основе международных медицинских шкал и методик.

## 🎯 Цель проекта

Автоматизировать процесс оценки тяжести состояния пациентов при поступлении в отделение/больницу с помощью:
- Быстрого ввода витальных показателей
- Автоматического расчета медицинских шкал (NEWS, MEWS, qSOFA)
- Определения уровня приоритета (триаж-категории)
- Генерации рекомендаций по немедленным действиям и плану наблюдения

## ✨ Основные возможности

### ✅ Реализовано

1. **Форма оценки пациента**
   - Ввод идентификационных данных (ID, возраст, пол, способ доставки)
   - Ввод витальных показателей:
     - ЧДД (частота дыхательных движений)
     - SpO₂ (сатурация кислорода)
     - Подача кислорода (да/нет, L/мин)
     - ЧСС (частота сердечных сокращений)
     - АД (артериальное давление систолическое/диастолическое)
     - Температура тела
     - Уровень сознания (шкала AVPU)
     - GCS (Glasgow Coma Scale)
   - Отметка клинических признаков (боль в груди, одышка, травма, кровотечение, судороги, нарушение сознания)

2. **Автоматический расчет медицинских шкал**
   - **NEWS (National Early Warning Score)** - диапазон 0-20
   - **MEWS (Modified Early Warning Score)** - диапазон 0-14
   - **qSOFA (Quick SOFA)** - диапазон 0-3

3. **Определение уровня триажа**
   - 🔴 **КРАСНАЯ (Resuscitation)** - реанимация, немедленная помощь
   - 🟠 **ОРАНЖЕВАЯ (Emergency)** - экстренная помощь в течение 10 минут
   - 🟡 **ЖЁЛТАЯ (Urgent)** - срочная помощь в течение 30 минут
   - 🟢 **ЗЕЛЁНАЯ (Semi-urgent)** - полусрочная помощь в течение 60 минут
   - 🔵 **СИНЯЯ (Non-urgent)** - несрочная помощь в течение 120 минут

4. **Автоматические рекомендации**
   - Список немедленных действий
   - План мониторинга пациента
   - Необходимые исследования
   - Индикатор требуемой эскалации помощи

5. **Список пациентов**
   - Просмотр всех оценённых пациентов
   - Сортировка по приоритету
   - Отображение актуальных триаж-категорий и баллов

6. **Статистика**
   - Общее количество пациентов
   - Средние значения шкал (NEWS, MEWS)
   - Средний приоритет
   - Распределение по триаж-категориям (визуализация)

7. **Хранение данных**
   - Cloudflare D1 (SQLite) база данных
   - История всех оценок
   - Логи действий
   - Связь пациентов с их оценками

## 📊 Используемые медицинские шкалы

### NEWS (National Early Warning Score)
Оценивает:
- ЧДД (частоту дыхания)
- SpO₂ (сатурацию кислорода)
- Подачу дополнительного кислорода
- ЧСС (частоту пульса)
- АД систолическое
- Температуру тела
- Уровень сознания (AVPU)

**Интерпретация:**
- 0-4: Низкий риск
- 5-6: Средний риск (требуется срочная помощь)
- 7+: Высокий риск (требуется экстренная помощь)

### MEWS (Modified Early Warning Score)
Упрощённая версия для быстрой оценки:
- ЧДД
- ЧСС
- АД систолическое
- Температура
- Уровень сознания (AVPU)

**Интерпретация:**
- 0-2: Низкий риск
- 3-4: Средний риск
- 5+: Высокий риск

### qSOFA (Quick SOFA)
Быстрая оценка риска сепсиса:
- ЧДД ≥ 22/мин
- Нарушение сознания
- АД систолическое ≤ 100 мм рт.ст.

**Интерпретация:**
- 0-1: Низкий риск сепсиса
- 2-3: Высокий риск сепсиса, рассмотреть перевод в ОРИТ

## 🗄️ Архитектура данных

### Таблицы базы данных

1. **patients** - Данные пациентов
   - ID, возраст, пол
   - Способ доставки
   - Жалоба
   - Время поступления

2. **triage_assessments** - Оценки триажа
   - Связь с пациентом
   - Все витальные показатели
   - Клинические признаки
   - Рассчитанные баллы (NEWS, MEWS, qSOFA)
   - Триаж-категория и приоритет
   - Рекомендации (действия, мониторинг, исследования)
   - Информация о враче

3. **triage_logs** - Аудит-логи
   - История всех действий
   - Связь с пациентом и оценкой
   - Временные метки

## 💻 Локальная разработка

### Установка

```bash
cd /home/user/webapp
npm install
```

```bash

npm run db:migrate:local

# Сбросить БД и применить миграции заново
npm run db:reset
```

```bash

npm run build

# 2. Запуск через PM2

```

```bash

```

## 📝 API Endpoints

### POST /api/triage/assess
Создать новую оценку пациента

**Request Body:**
```json
{
  "patient": {
    "patientId": "P12345",
    "age": 45,
    "gender": "male",
    "arrivalMode": "ambulance",
    "chiefComplaint": "Боль в груди"
  },
  "vitals": {
    "respiratoryRate": 22,
    "spo2": 92,
    "oxygenSupplementation": true,
    "oxygenFlow": 2,
    "heartRate": 105,
    "systolicBP": 140,
    "diastolicBP": 90,
    "temperature": 37.2,
    "consciousnessLevel": "alert",
    "gcsScore": 15
  },
  "features": {
    "chestPain": true,
    "dyspnea": true,
    "trauma": false,
    "bleeding": false,
    "seizures": false,
    "alteredMentalStatus": false
  },
  "assessedBy": "Dr. Smith"
}
```

**Response:**
```json
{
  "success": true,
  "patientId": "P12345",
  "assessmentId": 1,
  "scores": {
    "news": 6,
    "mews": 4,
    "qsofa": 1
  },
  "triage": {
    "level": "emergency",
    "color": "orange",
    "priorityScore": 70,
    "immediateActions": [...],
    "monitoringPlan": [...],
    "investigationsNeeded": [...],
    "escalationRequired": true
  }
}
```

### GET /api/triage/patients
Получить список всех пациентов с последними оценками

**Query Parameters:**
- `limit` (default: 50)
- `offset` (default: 0)

### GET /api/triage/patient/:patientId
Получить детальную информацию о пациенте со всеми оценками и логами

### GET /api/triage/stats
Получить статистику по всем пациентам

## ⚠️ Дисклеймер

Это приложение предназначено для помощи медицинским специалистам в процессе триажа. 
Оно не заменяет клиническую оценку врача и должно использоваться только как вспомогательный инструмент.
Окончательное решение о лечении пациента всегда остается за врачом.
