🔄 ОБНОВЛЕНИЕ ПРИЛОЖЕНИЯ:
   cd /home/user/webapp
   npm run build
   npx wrangler pages deploy dist --project-name triage-app

💾 БАЗА ДАННЫХ:
   • Локальная (для разработки):
     npx wrangler d1 execute triage-app-production --local --command="SELECT * FROM patients"
   
   • Production:
     npx wrangler d1 execute triage-app-production --remote --command="SELECT * FROM patients"

📦 MIGRATION КОМАНДЫ:
   • Применить миграции в production:
     npx wrangler d1 migrations apply triage-app-production --remote
   
   • Посмотреть список миграций:
     npx wrangler d1 migrations list triage-app-production
